## 不限流量VPS的三种口径：先分清流量和带宽

流量是一个月能传多少数据，带宽是每秒能传多快。不限流量只说明前者不设月上限，不代表后者不缩水。市面上常见的“不限流量”至少有三套写法，实际体验差很远。

| 口径 | 常见做法 | 实际体验 | 适合 |
| --- | --- | --- | --- |
| 窄带宽真不限 | 1Mbps 到 20Mbps 端口，流量无上限 | 1Mbps 理论峰值约125KB/s，满载一天约10GB；20Mbps 约2.5MB/s | 轻量挂机、小站、低频访问 |
| 大带宽真不限 | 200Mbps 到 500Mbps 端口，流量无上限 | 端口大，能长期跑；价格高 | 采集、多人共享、流媒体 |
| 不限流量加端口按套餐 | JustHost 300Mbps、400Mbps，端口公平共享，可加钱扩 | 月流量不封顶，官方折算300Mbps约93+TB/月；高峰期不保证满速 | 全球多机房、轻中度业务 |
| 不限流量加固定端口 | JustVPS 300Mbps 到 1Gbps | 流量无上限，端口固定，长周期价低 | 预算低、要多机房 |

JustHost 官方写得很清楚：所有套餐都含不限流量，流量是套餐属性，和机房位置无关；端口速度另算，300Mbps 标注“公平共享”，不是独享。需要更大端口，可以按 **+10Mbps ¥16.80/月** 加，或者上独享1Gbps **¥2240.85/月**。

看到“不限流量”四个字，先问三个问题：端口多少？独享还是共享？加带宽多少钱？这三个答案比“不限”两个字有用得多。

没有。JustHost 官方明确不提供自动备份，建议自己定期复制到另一台服务器，最好放在不同机房。备份不是可选项，跑业务尤其要提前做。
